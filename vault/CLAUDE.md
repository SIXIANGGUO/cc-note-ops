# Vault 工作规则

## 目录职责

- `控制中心/`：用户可见的工作台入口、资料入口和运行结果。
- `控制中心/资料入口/`：放项目、素材、账号、选题、历史作品等索引。
- `控制中心/运行结果/当前笔记/`：按钮运行后生成的公众号、小红书、选题和路标。
- `控制中心/备份/`：直接修改笔记前保存原文备份。
- `.cc-command-center/`：隐藏运行目录，放脚本和系统文件，普通使用不需要打开。

## 导航规则

1. 先读 `控制中心/资料入口/README.md`。
2. 不确定资料位置时，先列候选路径，再读取文件。
3. 不要全盘扫描整个 vault，除非用户明确要求。
4. 新增、移动、删除控制中心内文件后，更新对应 README。

## 写入规则

1. 当前笔记操作台的输出统一写入 `控制中心/运行结果/当前笔记/`。
2. 长期有效的素材入口写入 `控制中心/资料入口/`。
3. 修改原文前必须先备份到 `控制中心/备份/`。
4. 不删除文件；确需清理时，先列清单并等待确认。
